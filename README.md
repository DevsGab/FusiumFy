# 🎵 FusiumFy

> **Sua música. Do seu jeito.**

O **FusiumFy** é um player de música moderno, desenvolvido para oferecer uma experiência simples, rápida e personalizada para ouvir suas músicas favoritas.

## ✨ Recursos

* 🎵 Reprodução de músicas
* 📀 Playlists
* 📥 Importação de playlists
* 👥 Recursos sociais
* 🔄 Atualizações automáticas
* ⚡ Múltiplos servidores de áudio
* 🎨 Interface moderna
* 📱 Otimizado para Android
* 🚧 Reprodução offline em desenvolvimento

## 🆕 O que há de novo

A versão `2.5` traz melhorias de estabilidade, correções de bugs e melhorias na infraestrutura de áudio.

Também foi implementado um sistema com **dois servidores de áudio**, aumentando a disponibilidade do aplicativo caso um dos servidores apresente problemas.

A reprodução offline continua em desenvolvimento e deverá receber melhorias nas próximas versões.

## ⚠️ Aviso

O FusiumFy é um projeto independente e está em desenvolvimento contínuo.

Alguns recursos podem apresentar instabilidades ou mudanças entre versões.
